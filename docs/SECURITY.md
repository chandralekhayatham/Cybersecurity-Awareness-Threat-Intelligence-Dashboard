# Security & Privacy
- Never automatically visit suspicious URLs.
- Never contact suspicious IP/domain indicators.
- Never execute files from hashes.
- Use synthetic/demo data by default.
- Validate API inputs and keep analyst notes bounded.
- Keep secrets in environment variables for production.
- Add authentication/RBAC, rate limiting, HTTPS, audit logs and output sanitization before production use.
- Treat threat intelligence as evidence for investigation, not proof of compromise.
