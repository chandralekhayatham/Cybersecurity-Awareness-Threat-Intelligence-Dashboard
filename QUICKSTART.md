# Quick Start
1. Create/activate `.venv`.
2. `pip install -r requirements.txt`
3. `python data\generate_threat_data.py`
4. `pytest -v`
5. `python backend\app.py`
6. Open `http://127.0.0.1:5000`
7. Search `198.51.100.25` in IOC Search.
8. Open a threat from the SOC queue and inspect risk, confidence, indicators and ATT&CK context.
9. Complete the 30-question awareness quiz.
